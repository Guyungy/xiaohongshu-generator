# 版式系统（Layout System）

适用于：多页小红书 PNG/SVG 卡片，尤其是 `Mr Wong是码农` 连续图文。

## 核心原则

### 1. 每页只允许一个主结构
每页可以高信息密度，但必须只有一个主版式逻辑。

错误示例：
- Hero + 时间轴 + diff + checklist 同页乱堆
- 在旧版基础上继续加注释，导致阅读路径断裂

正确示例：
- Hero 页只承载封面和主结论
- diff 页只做对比
- timeline 页只做时间推进
- runbook 页只做方法落地

### 2. 高密度不等于堆字
信息密度提升的正确方式：
- 主结论
- 次级判断
- 补充说明
- 动作建议 / 结构锚点

不是通过长段落和过多 box 堆出来。

### 3. 阅读路径必须可见
每页都必须让人能一眼看出：
- 先看哪里
- 再看哪里
- 最后记住什么

---

## 推荐页面类型

至少覆盖 4 种，不要整组只用一种结构。

### 1. Hero 封面
适合：
- 第一页
- 大观点抛出
- 强情绪 / 强反差 / 强钩子

### 2. 左右分栏
适合：
- 旧价值 / 新价值
- 问题 / 方法
- before / after 的轻量版

### 3. 流程图 / 输入输出图
适合：
- 机制解释
- 为什么会这样
- 输入 → 处理 → 输出

### 4. diff / 矩阵对比
适合：
- 行为迁移
- 错误做法 vs 正确做法
- 旧模式 vs 新模式

### 5. 时间轴
适合：
- 渐进变化
- 行为形成过程
- “未来如何进入日常”类内容

### 6. runbook / action card
适合：
- 最后一页
- 可复制模板
- 落地动作

## Mr Wong 页面专属规则

### 允许出现的视觉语言
- 箭头
- diff 符号
- 状态词（STATUS / NOTE / TODO / RISK）
- 接口、协议、runbook、验收、输入输出
- 设备轮廓、简化结构图

### 禁止出现的版式问题
- 每页像模板复印件
- 所有文字都塞进方框
- 一页出现过多同级区块
- 为了信息密度牺牲秩序
- 在 V4/V5 这类旧结构上继续补丁式加字

---

## 重做判定（必须 re-design）

若上一版出现以下任一情况，下一版必须 **re-design**，不能只补充内容：

- 用户指出“每页都一样”
- 用户指出“区块太多”
- 用户指出“信息密度加上去了，但排版乱了”
- 页面阅读主路径不清晰
- 版式已经承载不了新增信息

这类情况必须：
1. 先重做信息层级
2. 再重做版式
3. 最后再补文字

禁止继续在旧版上打补丁。
