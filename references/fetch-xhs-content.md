# 小红书内容获取指南

由于小红书的反爬虫机制，无法直接通过API获取内容。本文档提供多种实用的替代方案。

---

## 问题说明

小红书链接（xhslink.com）无法直接访问的原因：
- ❌ 严格的反爬虫策略
- ❌ 需要登录态和特定cookie
- ❌ 短链接可能有时效性
- ❌ 动态渲染的内容需要浏览器环境

---

## 推荐方案

### 方案1：直接复制粘贴（最简单）⭐⭐⭐⭐⭐

**步骤：**
1. 在小红书App/网页打开笔记
2. 复制完整内容
3. 使用skill时粘贴内容

**输入格式：**
```
生成小红书内容：

【简述】
吉赛尔芭蕾舞剧第二幕解读

【参考内容】
[粘贴完整的小红书笔记文本]
```

**优点：**
- ✅ 100%可靠
- ✅ 无需任何工具
- ✅ 内容最完整

---

### 方案2：使用浏览器书签工具 ⭐⭐⭐⭐

创建一个浏览器书签，一键提取页面内容：

**书签代码（Bookmarklet）：**
```javascript
javascript:(function(){
  const content = document.querySelector('.note-text, .content, [class*="content"]');
  const title = document.querySelector('h1, .title, [class*="title"]');

  let text = '【标题】\n' + (title?.innerText || '未找到标题') + '\n\n';
  text += '【内容】\n' + (content?.innerText || document.body.innerText.substring(0, 2000));

  const textarea = document.createElement('textarea');
  textarea.value = text;
  document.body.appendChild(textarea);
  textarea.select();
  document.execCommand('copy');
  document.body.removeChild(textarea);

  alert('✅ 内容已复制到剪贴板！');
})();
```

**如何使用：**
1. 在浏览器中创建新书签
2. 将上面的代码粘贴到书签的URL字段
3. 打开小红书笔记页面
4. 点击这个书签
5. 内容自动复制到剪贴板
6. 粘贴给skill使用

### 方案3：使用辅助脚本 ⭐⭐⭐

我已经创建了一个Python辅助脚本：`tools/fetch_xhs.py`

**使用方法：**

```bash
# 方式1：从剪贴板读取（先在浏览器复制内容）
python3 tools/fetch_xhs.py --clipboard

# 方式2：从文件读取
python3 tools/fetch_xhs.py --file content.txt

# 方式3：交互式输入
python3 tools/fetch_xhs.py
# 然后粘贴内容，输入END结束
```

**安装依赖（可选）：**
```bash
pip install pyperclip  # 用于剪贴板操作
```

## 常见问题

**Q: 为什么不能直接支持小红书链接？**
A: 小红书有严格的反爬虫机制，保护用户内容和平台数据。直接抓取会被识别和阻止。

**Q: 复制粘贴会不会很麻烦？**
A: 实际使用中，复制粘贴是最快且最可靠的方式。配合书签工具，一键即可完成。

**Q: 有没有更自动化的方法？**
A: 技术上可行，但需要：
- 浏览器自动化（复杂度高）
- 或小红书官方API（个人难获取）
- 权衡成本后，手动方式是最佳选择

**Q: 可以支持其他平台吗？**
A: 可以！以下平台的链接通常可以直接访问：
- ✅ 个人博客、Medium
- ✅ GitHub、技术文档站
- ✅ 新闻网站（部分）
- ⚠️ 知乎、公众号（可能有限制）
- ❌ 微博、抖音（类似小红书）
