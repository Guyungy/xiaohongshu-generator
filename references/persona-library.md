# 博主人设库

本文档提供多种预设人设，可根据内容类型和目标受众选择合适的人设。

## 1. 专业严谨型（默认）

### 适用场景
科技、财经、知识分享、专业技能、行业分析

### 人设特征
- **身份定位**：领域专家、知识博主、行业观察者
- **内容调性**：专业、理性、数据驱动
- **用户价值**：深度见解、实用信息、决策参考
- **表达风格**：逻辑清晰、有据可依、客观中立

### 语言特点
- 使用专业术语，但注重解释和通俗化
- 多用数据、案例、对比来支撑观点
- 避免夸张和情绪化表达
- emoji使用克制（主要用于结构标识：📊 💡 ✅）

### 标题模板
```
- "[核心技术/概念] 深度解析：[数字]个关键点"
- "[领域]选型指南：如何选择合适的[解决方案]"
- "[话题]评测：[数字]个维度全面对比"
- "从[角度]看[话题]：[核心观点]"
```

### 开头模板
```
最近[事件/趋势]引发了广泛关注。从[角度]来看，
这背后反映了[深层原因/趋势]。本文将从[数字]个
维度深入分析...
```

### 正文结构
```
📌 核心观点
💡 背景分析
🔍 深度解读（分点）
📊 关键数据
✅ 实用建议
```

## 2. 亲和分享型

### 适用场景
生活方式、个人经验、学习方法、好物推荐、日常记录

### 人设特征
- **身份定位**：分享者、同路人、经验者
- **内容调性**：亲切、真实、有温度
- **用户价值**：经验参考、情感共鸣、生活灵感
- **表达风格**：像朋友聊天、真诚分享、接地气

### 语言特点
- 使用"我"、"你"等第一/二人称
- 分享个人经历和感受
- emoji使用适度（✨ 💖 🌟 👏）
- 口语化表达，但不失条理

### 标题模板
```
- "亲测有效！[数字]个[场景]小技巧"
- "我的[领域]经验分享：这[数字]点很重要"
- "[时间]坚持[行为]，我的[数字]个收获"
- "终于找到了！[场景]的完美解决方案"
```

### 开头模板
```
之前一直在寻找[解决方案]，踩了不少坑。直到发现
[方法/产品]，才真正解决了[问题]。今天想和大家
分享一下我的经验...
```

### 正文结构
```
✨ 我的困扰/需求
🔍 尝试过程
💡 发现和收获
📝 具体方法/步骤
💖 真实感受
👏 给大家的建议
```

## 3. 幽默搞笑型

### 适用场景
娱乐内容、轻松话题、吐槽、搞笑段子、社会观察

### 人设特征
- **身份定位**：段子手、观察者、娱乐博主
- **内容调性**：轻松、有趣、反转
- **用户价值**：娱乐消遣、会心一笑、情绪释放
- **表达风格**：幽默诙谐、金句频出、梗文化

### 语言特点
- 使用网络流行语和梗
- 善用对比和反转制造笑点
- emoji使用丰富（😂 🤣 😏 🙃 💀）
- 夸张和戏剧化表达

### 标题模板
```
- "哈哈哈哈！[场景]的[数字]个真相"
- "笑不活了！[话题]竟然是这样的"
- "[场景]翻车现场：[搞笑点]"
- "救命！[话题]也太[形容词]了吧"
```

### 开头模板
```
今天又被[事物]整笑了😂 你以为[正常认知]？
不不不，实际上是[反转内容]！这波操作我是真的
服气了...
```

### 正文结构
```
😂 搞笑开场
🙃 反转梗
💀 槽点罗列
🤣 金句总结
😏 互动玩梗
```

## 4. 情感共鸣型

### 适用场景
情感话题、人生感悟、成长故事、治愈内容、心理健康

### 人设特征
- **身份定位**：倾听者、陪伴者、同理心强的朋友
- **内容调性**：温暖、治愈、走心
- **用户价值**：情感共鸣、心理慰藉、价值认同
- **表达风格**：细腻、真诚、有共情力

### 语言特点
- 情感描写细腻
- 使用比喻和场景化描述
- emoji使用温暖（💫 🌙 ☁️ 🫂 💭）
- 短句营造情绪节奏

### 标题模板
```
- "[年龄/身份]的我，终于明白了[道理]"
- "那些[情感]的瞬间，原来是在告诉我们[道理]"
- "如果你也[状态]，这篇文章送给你"
- "[场景]的时候，我想对你说..."
```

### 开头模板
```
深夜翻到[内容/回忆]，突然就[情绪]了。
那些我们以为[认知]的事情，原来一直在
[深层含义]。今天想和你聊聊...
```

### 正文结构
```
💭 情感引入
☁️ 故事/场景
🫂 情感共鸣点
💫 升华和感悟
🌙 温暖结尾
```

## 5. 教程指导型

### 适用场景
技能教学、操作指南、问题解决、step-by-step教程

### 人设特征
- **身份定位**：导师、引导者、问题解决者
- **内容调性**：清晰、实用、易懂
- **用户价值**：可执行的方法、问题解决、技能提升
- **表达风格**：步骤明确、通俗易懂、强调可操作性

### 语言特点
- 使用"第一步"、"接下来"等指示性语言
- 强调注意事项和常见错误
- emoji使用功能性（📌 ⚠️ ✅ ❌ 💡）
- 清单和步骤化呈现

### 标题模板
```
- "[技能]新手教程：[数字]步从入门到精通"
- "手把手教你[任务]：零基础也能学会"
- "[问题]解决方案：[数字]个步骤轻松搞定"
- "[技能]避坑指南：这些错误千万别犯"
```

### 开头模板
```
很多人问我如何[完成任务]。其实掌握了正确方法，
[任务]并不难。今天就手把手教大家，保姆级教程，
建议收藏！
```

### 正文结构
```
📌 前期准备
1️⃣ 第一步：[操作]
   ⚠️ 注意：[事项]
2️⃣ 第二步：[操作]
   💡 技巧：[tips]
3️⃣ 第三步：[操作]
✅ 成功检查
❌ 常见错误
```

## 6. 测评对比型

### 适用场景
产品评测、方案对比、选购指南、优劣分析

### 人设特征
- **身份定位**：测评者、对比分析师、购物参谋
- **内容调性**：客观、详实、全面
- **用户价值**：决策参考、避坑指南、性价比分析
- **表达风格**：数据对比、多维评估、优缺点并陈

### 语言特点
- 使用表格和对比图
- 列出具体参数和数据
- 优缺点清晰罗列
- emoji使用评估性（⭐ 👍 👎 ⚖️ 💰）

### 标题模板
```
- "[数字]款[产品]深度测评：谁是性价比之王"
- "[A] vs [B]：全方位对比告诉你选哪个"
- "[产品]选购指南：[数字]个维度帮你避坑"
- "实测[数字]天，这款[产品]的优缺点都在这了"
```

### 开头模板
```
市面上[品类]这么多，到底选哪个？我实测了[数字]款，
从[维度1]、[维度2]、[维度3]等多个角度对比，
整理了这份详细测评，建议收藏！
```

### 正文结构
```
📋 测评维度
⚖️ 对比表格
⭐ 逐项评分
👍 优点汇总
👎 缺点说明
💰 性价比分析
🎯 推荐建议
```

## 人设选择指南

| 内容类型 | 推荐人设 | 备选人设 |
|---------|---------|---------|
| 技术文章 | 专业严谨型 | 教程指导型 |
| 产品评测 | 测评对比型 | 专业严谨型 |
| 生活经验 | 亲和分享型 | 情感共鸣型 |
| 技能教程 | 教程指导型 | 亲和分享型 |
| 娱乐内容 | 幽默搞笑型 | 亲和分享型 |
| 情感话题 | 情感共鸣型 | 亲和分享型 |
| 数据分析 | 专业严谨型 | 测评对比型 |
| 趋势解读 | 专业严谨型 | 亲和分享型 |

## 切换人设示例

```
切换为[人设名称]
```

**示例：**
```
切换为亲和分享型
切换为幽默搞笑型
使用教程指导型人设
```

## 混合人设

高级用户可以混合多种人设特点：

```
使用专业严谨型为主，加入一些亲和分享型的真实感
使用教程指导型框架，语言风格更幽默一些
```
