# 小红书内容安全指南

确保生成的内容符合平台规范，避免限流、删帖和封号风险。

## 敏感词分类

### 🔴 高危违禁词（绝对禁止）

#### 医疗健康类
```
❌ 治愈、根治、疗效、药到病除
❌ 处方药名称（XX片、XX胶囊）
❌ 疾病治疗承诺
❌ 医疗器械未经认证的功效

✅ 替代表达：
"缓解" 而非 "治疗"
"辅助改善" 而非 "治愈"
"健康管理" 而非 "疾病治疗"
```

#### 金融理财类
```
❌ 保证收益、稳赚不赔
❌ 投资建议、炒股技巧
❌ 具体收益率承诺
❌ 借贷、贷款、信用卡套现

✅ 替代表达：
"理财经验分享" 而非 "投资建议"
"历史数据参考" 而非 "收益保证"
"风险提示：投资需谨慎"
```

#### 政治敏感类
```
❌ 时政话题、政治人物
❌ 敏感历史事件
❌ 宗教极端内容
❌ 地域歧视、民族矛盾

✅ 做法：
完全避开此类话题
如必须涉及，仅陈述客观事实
```

#### 虚假宣传类
```
❌ 最好、第一、唯一、顶级
❌ 国家级、世界级（未经认证）
❌ 100%、绝对、一定
❌ 全网最低价、史上最优

✅ 替代表达：
"非常好" 而非 "最好"
"值得推荐" 而非 "必买"
"性价比高" 而非 "全网最低"
"参考" 而非 "一定"
```

#### 引流违规类
```
❌ 微信、VX、WX、威信
❌ 私信、加我、联系我
❌ 外部链接、二维码
❌ 电话号码、邮箱地址

✅ 替代表达：
"评论区交流" 而非 "私信我"
"主页查看" 而非 "加微信"
```

---

### 🟠 中危灰色词（需谨慎使用）

#### 夸张表达
```
⚠️ 神器、绝绝子、YYDS
⚠️ 爆款、疯抢、秒杀
⚠️ 必买、必看、必收藏

💡 使用建议：
可以适度使用，但不要频繁出现
专业严谨型人设应避免使用
搭配客观信息平衡
```

#### 对比暗示
```
⚠️ 完胜XX、吊打XX
⚠️ 秒杀XX、碾压XX
⚠️ 不输XX、不比XX差

💡 使用建议：
使用客观对比数据
避免直接贬低其他品牌
保持中立评价
```

#### 效果承诺
```
⚠️ 立竿见影、马上见效
⚠️ 一次解决、永久有效
⚠️ 所有人都适用

💡 使用建议：
添加"个人体验"、"仅供参考"
说明适用条件和局限性
避免绝对化表述
```

---

### 🟡 低危注意词（建议替换）

#### 广告痕迹强的词
```
原词 → 替代词

购买 → 入手、选择
推荐 → 分享、用过
便宜 → 性价比高、价格友好
促销 → 活动、优惠
```

#### 过度营销词
```
原词 → 替代词

抢购 → 关注
火爆 → 受欢迎
断货 → 供不应求
必买 → 值得考虑
```

## 内容风险等级判定

### 风险评估维度

| 维度 | 检查项 | 安全标准 |
|-----|--------|---------|
| 敏感词 | 是否包含高危词 | 0个高危词 |
| 夸张度 | 绝对化表达频率 | <3次/千字 |
| 商业化 | 品牌露出密度 | <5次/千字 |
| 引流性 | 引导站外行为 | 完全避免 |
| 争议性 | 可能引发争议的观点 | 客观中立 |

### 风险等级

#### 🟢 低风险（可直接发布）
- 无敏感词
- 无绝对化表达
- 商业化痕迹轻
- 无引流行为
- 内容积极正面

#### 🟡 中风险（需优化）
- 包含1-2个灰色词
- 有夸张表达但不严重
- 商业化明显但合规
- 需调整部分表述

#### 🟠 高风险（必须修改）
- 包含高危词
- 绝对化表达频繁
- 明显引流行为
- 虚假宣传嫌疑
- 可能引发争议

#### 🔴 严重违规（不可发布）
- 多个高危词
- 涉及政治敏感
- 医疗金融违规
- 明显虚假宣传
- 引流信息

## 平台规则变化跟踪

### 2024-2025年新规

1. **AI生成内容标注**
   - 建议：AI生成内容可标注"部分内容AI辅助生成"
   - 不强制，但提高可信度

2. **知识类内容资质要求**
   - 医疗、法律、金融类需专业背景
   - 建议：添加"个人观点，仅供参考"

3. **商业内容标注**
   - 广告内容必须标注"广告"或"推广"
   - 即使自然分享，涉及利益也应透明

4. **标题党限制**
   - 避免"震惊"、"吓傻"、"不敢相信"
   - 标题需与内容高度相关

## 特殊场景处理

### 产品推荐

**安全做法：**
1. 先讲痛点/需求，再引出产品
2. 提及优缺点，增加真实感
3. 说明个人使用场景
4. 添加"个人经验，仅供参考"

**禁止做法：**
1. 标题直接品牌名
2. 全文推销，无真实体验
3. 价格引导
4. 外部链接

### 知识科普

**安全做法：**
1. 引用权威来源
2. 说明适用范围
3. 添加免责声明
4. 鼓励咨询专业人士

**禁止做法：**
1. 医疗建议
2. 法律指导
3. 金融建议
4. 未经证实的信息

### 经验分享

**安全做法：**
1. 明确是个人经验
2. 说明"因人而异"
3. 客观描述过程
4. 欢迎交流讨论

**禁止做法：**
1. 宣称适用所有人
2. 效果绝对化
3. 贬低其他方法
4. 引流到站外

## 应急处理

### 如果内容被限流

1. **自查原因**
   - 回顾敏感词
   - 检查商业化程度
   - 确认是否引流

2. **修改策略**
   - 删除敏感表述
   - 降低商业痕迹
   - 调整标题和首段

3. **重新发布**
   - 不要立即重发
   - 间隔4-6小时
   - 修改后再发

### 如果收到违规通知

1. **立即删除/修改**
2. **分析违规原因**
3. **建立规避清单**
4. **申诉（如果误判）**

---

## 最佳实践建议

1. **宁可保守，不要冒险**
   - 有疑虑的词就换掉
   - 敏感话题完全避开

2. **真实分享，避免营销**
   - 真实体验最安全
   - 过度营销易违规

3. **客观表达，避免绝对**
   - 加上"个人观点"
   - 说明"仅供参考"

4. **定期学习平台规则**
   - 关注平台公告
   - 学习优质账号

5. **建立内容审核流程**
   - 发布前必过一遍清单
   - 重要内容请他人审阅

---

**记住：内容安全是第一位的，再好的内容如果违规也是白费功夫！**
