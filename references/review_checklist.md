# 验收清单（Review Checklist）

适用于：小红书图文卡片最终出图前的自查。

## 内容验收

- [ ] 标题是否足够清晰、够大、可一眼读懂
- [ ] 每页是否有明确主结论
- [ ] 信息密度是否足够，但没有靠长段落硬堆
- [ ] 文案是否符合 persona 风格
- [ ] `post.md` 是否完整
- [ ] 标签数量是否控制在 8 个以内（默认）

## 视觉验收

- [ ] 每页是否有独立版式
- [ ] 整组是否至少覆盖 4 种结构
- [ ] 重点文字与解释文字是否分层
- [ ] 图形元素是否参与叙事，而不是纯装饰
- [ ] 页面是否避免“过于工整 / 模板复印件感”
- [ ] 是否没有多余页码标识（如用户明确禁止）

## 节奏验收

- [ ] 翻页时视觉重心有变化
- [ ] 留白有变化
- [ ] 页面类型有变化
- [ ] 阅读路径清楚，不会乱跳

## 品牌 / 植入验收

- [ ] 若指定固定页脚，是否每页都保留
- [ ] 植入是否稳定但不生硬

## 文件验收

- [ ] PNG 数量正确
- [ ] 命名规范正确
- [ ] `post.md` 已生成
- [ ] 若需要，`tar.gz` 已成功生成

## 交付验收

- [ ] 若用户要求“发到群里”，是否已经真的发出
- [ ] 若 Telegram 工具报 poll 错误，是否已切 CLI fallback
- [ ] 不允许把“本地文件已生成”误判为“已交付完成”
