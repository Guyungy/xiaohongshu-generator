# “驻校艺术家手记”内容结构逻辑与叙事策略

## 1. 篇幅标准与叙事逻辑

- **篇幅标准**: 固定 `3～6` 页。
- **叙事逻辑**: 每一组内容必须遵循以下六段式叙事逻辑：P1 封面 → P2 现象/溯源 → P3 深度洞察 → P4 现场植入 → P5 价值/干货 → P6 结语。

### P1 封面 (The Hook)
- **视觉**: 大标题、富有视觉冲击力的图片预留位、栏目刊头（如“驻校艺术家手记”）。
- **内容**: 提出一个反直觉的问题、社会痛点或强烈的悬念，迅速抓住读者注意力。
    - **示例**: “别把美育当杂技：孩子学艺术，到底学的是什么？”

### P2 现象/溯源 (The Context)
- **目的**: 深入分析当前的社会现象、普遍误区、家长焦虑，或追溯艺术家本人与艺术结缘的背景故事。
- **内容形式**: 
    - 使用**对比表**（如“大众误解 VS 事实真相”）来清晰展现认知差异。
    - 呈现相关数据或案例，为后续的深度洞察做铺垫。

### P3 深度洞察 (The Insight)
- **目的**: 针对P1提出的问题和P2铺垫的背景，提出核心观点，进行深度解构。
- **内容形式**: 
    - 阐述艺术的心理机制、教育的底层逻辑、艺术的内核价值等。
    - 大量使用**图解模型**（如金字塔、冰山图、思维导图等）将抽象概念可视化，帮助读者理解。

### P4 现场植入 (The Implant)
- **目的**: 将抽象的理念与具体的实践相结合，必须包含机构（YCIS/YWIES）的真实场景。
- **内容**: 
    - 结合学校（YCIS/YWIES，可具体到临港校区）的真实艺术课堂实录、学生作品、艺术家工作坊、校园文化活动或观察笔记。
    - 展示学校独特的教育理念和实践（如“无墙教室”、“反效率课堂”、“艺术融入学科”）。

### P5 价值/干货 (The Value)
- **目的**: 为家长和读者提供具体、可执行的价值，升华教育意义。
- **内容**:
    - **具体建议**: “回家问孩子三个关于艺术的问题，开启高质量对话”。
    - **行动指南**: “家长如何在日常生活中培养孩子的审美力”。
    - **升华教育意义**: “艺术是情绪的避难所，更是创造力的源泉”。

### P6 结语 (The Conclusion)
- **金句总结**: 以一句富有哲理或感染力的金句作结，深化主题。
- **情感号召**: 鼓励读者进行思考、行动或分享。
- **固定落款**: **驻校艺术家手记 @ 上海耀中耀华 + [日期]**。

## 2. 补充：关于头像绘制 (Avatar)

- **风格**: 极简矢量卡通 (Vector Cartoon)。
- **抓取特征**: 精准捕捉人物的独特特征，如发型（蓬松卷发）、五官神态（单眼皮、平静感）、标志性服饰。
- **形式**: SVG 格式，圆形裁剪。
