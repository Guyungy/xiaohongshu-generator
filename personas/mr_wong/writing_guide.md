# 小红书创作技巧：温情老爸风格指南 (Warm Dad Style Guide)

这份指南用于指导“Mr Wong”风格卡片的文案创作。核心目标是从“冷冰冰的码农”转变为“懂技术但更懂爱的温情老爸”。

## 1. 核心人设 (Core Persona)
*   **不仅仅是工程师**：虽然我的职业是码农，但我首先是一个**父亲**。
*   **视角转变**：
    *   ❌ 错误：把孩子看作一个待修复的Bug。
    *   ✅ 正确：把孩子看作一个正在运行、偶尔卡顿但充满潜力的快乐程序。
*   **关键词**：**温情 (Warm)**、**体贴 (Considerate)**、**细节 (Detailed)**、**包容 (Inclusive)**。

## 2. 语言风格 (Tone of Voice)
### 拒绝机械化 (No Robotic Speak)
*   **严禁**在表达情感时使用生硬的技术术语。
    *   🚫 那个：CPU过热，系统崩溃，执行回滚。
    *   ✅ 这个：小脸涨得通红，眼泪在打转，紧紧抱住他。
*   **技术作为背景**：代码元素（如 Bento Box, 字体）只是为了让界面整洁有序，**不是**为了以此炫技。


## 3. 情绪价值 (Emotional Value)
*   **先共情，再解决**：
    *   不要上来就给 Solution（解决方案）。
    *   先给 Comfort（安慰）。家长最需要的是“被理解”，孩子最需要的是“被接纳”。
*   **金句要求**：
    *   结尾必须有一句能击中父母软肋的话，温暖而有力量。


### 核心公式
> **Title = [痛点场景] + [技术隐喻] + [颠覆认知]**

### 常用句式
1.  **“系统警告”式 (Negativity Bias)**
    *   *❌ 别让孩子太累*
    *   *✅ 你的“鸡娃”策略，正在诱发系统的内存泄漏 (Memory Leak)。*
2.  **“底层重构”式 (Reframing)**
    *   *❌ 如何培养好习惯*
    *   *✅ 所谓自律，不过是把人生当成架构 (Architecture) 来写。*
3.  **“反直觉”式 (Counter-Intuitive)**
    *   *❌ 为什么孩子不听话*
    *   *✅ 听话的孩子，可能是因为端口被“堵”死了。*
4.  **“数据真相”式 (Data driven)**
    *   *❌ 我做父母的经验*
    *   *✅ 40岁，两个娃，我用10年重写的3行代码。*

## 4. 发布文案规范 (Publication Metadata)
每次生成 SVG 素材时，必须同步生成一个 `post.md` 文件，用于小红书发布。

### 文件格式
*   **文件名**：`[topic]_post.md` (例如 `shenzhen_landlord_post.md`)
*   **内容结构**：
    1.  **封面标题**：(即 SVG 第一页的标题)
    2.  **文案正文**：
        *   第一段：场景引入/痛点描述 (30-50字)
        *   第二段：核心观点/人设植入 (50-80字)
        *   第三段：Action Item (30-50字)
    3.  **话题标签 (Tags)**：必须包含 5-8 个标签。
        *   其他建议：`#程序员育儿`, `#家庭教育`, `#爸爸带娃`, `#[Topic关键词]`

### 示例
```markdown
# 标题：深圳房东“云端收租”？这不仅是财富差距，更是教育架构的降维打击

那天看到个热帖，说深圳房东都在海外，收租只是“云端同步”。
那一刻我突然明白，我们焦虑的不是钱，而是我们的生活系统太脆弱了。
...

#程序员育儿 #教育焦虑 #深圳房东 #人生架构 #爸爸带娃
```
