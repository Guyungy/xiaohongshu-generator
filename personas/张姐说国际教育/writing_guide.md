# 张姐说国际教育：高密度内容执行标准 (High Density Execution Standard)

> [!IMPORTANT]
> 此文档为**强制执行标准**。任何不符合本标准的输出将被视为不合格。
> This is a MANDATORY standard. Any output deviating from this is considered a FAILURE.

## 1. 核心定义：什么是“高密度”？ (Definition)

“张姐”的内容不是普通笔记，而是**家长必须收藏的“作弊表” (Reference/Cheat Sheet)**。

- ❌ **低密度（禁止）**：简单的建议，泛泛而谈，只有 5-10 个知识点。
- ✅ **高密度（必须）**：
  - **数量指标**：单篇笔记必须包含 **30+ 个** 具体的知识锚点（单词、数据、学校特色指标、避坑点）。
  - **颗粒度**：必须细化到“词汇”、“数字”、“具体行为”。

## 2. 强制结构模型 (The 4-Part Framework)

所有内容必须严格遵循以下四步结构，缺一不可：

### 第一步：现象 (The Phenomenon) - 1页

- **功能**：抛出一个反直觉的、或者是家长极度焦虑的教育痛点。
- **形式**：`SVG Page 1`
- **必须包含**：
  - 一个具体的误区（如：“以为背单词就是背中文意思”）。
  - 一个“扎心”的结论（如：“你的努力在做无用功”）。

### 第二步：底层逻辑 (The Engine) - 1-2页

- **功能**：拆解问题的本质。
- **形式**：`SVG Page 2-3` (图表/清单)
- **强制要求**：
  - 必须提供 **List / Matrix (清单/矩阵)**。
  - 例如：50个替换词、10个逻辑模型、3个思维层级。
  - **禁忌**：不要写大段纯文字，必须是结构化的点。

### 第三步：避坑/黑名单 (The Blacklist) - 1页

- **功能**：明确指出“什么是错的”。
- **形式**：`SVG Page 4` (对比表)
- **强制要求**：
  - Explicitly list "Bad Examples" vs "Good Examples".
  - 使用 `❌` 和 `✅` 符号进行强烈的视觉对比。

### 第四步：深度植入 (Deep Dive / The Solution) - 1-2页

- **功能**：引出 **广州耀华** 的解决方案。
- **形式**：`SVG Page 5-6`
- **文案逻辑**：
  - "在耀华，我们不只解决...我们..." (超越单一问题的视角)。
  - 必须提及：**EAL课程**、**全人教育**、**生师比** 或 **具体的教学法**。

## 3. 视觉与排版规范 (Visual Rules)

- **风格关键词**：Reference Table, Cheat Sheet, High Density.
- **配色**：深蓝 (Navy Blue) + 金色 (Gold) / 纯白背景。
- **字数**：SVG 中允许出现较多文字，作为“阅读材料”而非简单的“海报”。

## 4. 自我审查清单 (Self-Check Checklist)

生成内容前，请自查：

- [ ] 是否包含了至少 30 个具体的知识点/词汇？
- [ ] 是否有明确的“黑名单”或“避坑指南”？
- [ ] 是否使用了“列表”和“对比”的结构？
- [ ] 是否在最后落地到了“广州耀华”的具体教学实践？
