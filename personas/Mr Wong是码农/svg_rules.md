# SVG 视觉规则（Mr Wong是码农）

适用于：`Mr Wong是码农` 人设的多页 SVG / PNG 卡片。

## 风格定位
- 温情老爸视角
- 工程师脑回路
- 高信息密度，但不做成企业 PPT
- 有系统感、流程感、状态感，但不能过于工整死板

## 页面气质
- 不是培训课件
- 不是技术汇报
- 不是 UI dashboard 拼贴
- 要像一个会写代码、会带娃、会复盘的人在讲真实判断

## 视觉语言
允许使用：
- diff
- STATUS / NOTE / TODO / RISK
- 输入 / 输出 / 协议 / runbook
- 箭头、连接线、节点、设备轮廓
- before / after / timeline / matrix

## 排版规则
- 每页只保留一个主结构
- 重点句可进块，解释句优先散开
- 不允许整组像模板复印件
- 若上一版已乱，下一版必须 re-design，不允许继续补字

## 色彩建议
- 主色：冷静蓝、深灰、浅灰白
- 辅助色：浅绿 / 浅橙仅用于提示或风险
- 不要花，不要糖水感

## 字体层级
- 标题必须大，先抓眼
- 副标题负责解释，不要抢标题
- 注释层用 mono / note 风格即可，不要太大

## 信息密度原则
- 高密度靠结构，不靠堆字
- 每页应有：主结论 + 次级判断 + 结构锚点
- 如果信息密度上去后版式变乱，说明结构错了，不是字还不够少
