# 🎯 小红书多人设内容生成 Skill

**「深度人设 · 极致视觉 · 智能分发」**

专为小红书（Xiaohongshu）打造的高端内容生成系统

它不仅能抓取和重写文案，更能深度定制博主人设，并自动生成具备**极高信息密度**的 **SVG 视觉卡片**

本系统更强调“人性的观察”与“专业的视觉布局”


## 🚀 核心优势与特点

### 1. 深度人设系统 (Advanced Persona)

### 2. 固定视觉表现 (Visual Excellence)

### 3. 高信息密度 (High Information Density)
我们坚信内容为王。系统在生成时严格遵循：

自动分析复杂话题（如理财利息、教育心理、艺术疗愈），并转化为易于吸收的视觉信息流

### 4. 智能内容抓取 (Smart Extraction)
可真实模拟访问并抓取小红书、微信等平台的受限内容

输入链接或零散观点，系统自动按照目标人设进行全量重构


## 🛠️ 工作流优化 (Optimized Workflow)

本 Skill 采用了 **[分析 -> 直接生成]** 的高效模型：
1. **语义分析**: 深度解析原文的核心逻辑、关键数据点与情感基调。
2. **人设重映射**: 将原文信息平移至目标人设的视角，注入特定的口吻。
3. **视觉布局生成**: 直接根据信息体量计算 SVG 布局，无需中间草稿。
4. **全套输出**: 2～6页视觉 SVG 卡片 + 1份 SEO 优化笔记文案 (`post.md`)。


## ⚡ 快速使用

只需一行指令，即可启动生成：

根据选题生成内容
```markdown
生成内容 [人设名] [选题]
```

根据输入参考笔记链接生成内容

```markdown
使用[人设名]，重写：http://xhslink.com/o/xxxx
```

生成新的人设
```markdown
生成人设：[人设名]
定位：[人设定位]
笔记风格：[笔记风格]
```
